# 自动定位文档（auto-locate-doc）

打开或切换文档时，左侧文件树自动展开祖先并把当前文档滚动到可见位置；点击文档内任意块时，如果文件树还没有跟上，也会执行一次定位。

## 行为

- **切换 / 打开文档**：监听 protyle 加载与切换事件，调用文件树模型的 `selectItem(notebookId, path)` 定位当前文档。
- **点击块**：监听文档区域的点击，若文件树尚未位于当前文档则定位一次。
- **去重**：同一文档 1 秒内只处理一次，避免连续触发。

## 设置

| 开关 | 默认 | 说明 |
| --- | --- | --- |
| 启用自动定位 | 开 | 总开关，关闭后不做任何动作 |
| 点击块时定位 | 开 | 在正文点击块时是否也触发定位 |

## 边界

- 仅声明 `desktop` 前端，未适配 mobile / browser。
- 只读：不修改任何笔记、块、数据库；唯一写入是通过 `Plugin.saveData` 保存本插件配置。
- 文件树面板未打开或无当前编辑器时静默跳过。
- 卸载时移除全部事件监听与定时器。

## 卸载

在集市中停用或卸载即可；停用后不再有任何监听残留。
